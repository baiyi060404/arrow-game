# arrow-game（一箭又一箭）

## 项目简介

《一箭又一箭》是一款基于 Pygame 的网格解谜小游戏。棋盘上分布着不同方向、不同长度的箭头，点击箭头后箭头会像蛇一样逐格向前移动，身体段依次跟随。玩家需要判断箭头前方是否存在阻挡，让所有箭头安全飞出棋盘。

游戏包含：

- 三个普通关卡：9x9、11x11、13x13
- 无尽模式：随机生成可通关地图，失误耗尽后结束
- 得分、计时和星级评价
- 成功滑出与碰撞提示音效

## 开发环境

- 操作系统：Windows
- Python：3.11 或更高版本
- Pygame：2.6.x
- 主要开发文件：`main.py`

## 安装和运行

### 1. 安装依赖

```powershell
pip install -r requirements.txt
```

### 2. 运行游戏

在项目目录下执行：

```powershell
python main.py
```

## 游戏操作说明

### 主菜单

![主界面](UI.png)

- 开始游戏：进入选关界面
- 设置：切换窗口模式 / 全屏模式
- 离开游戏：退出程序

### 选关界面

- 第 1 关：9x9 棋盘
- 第 2 关：11x11 棋盘
- 第 3 关：13x13 棋盘
- 无尽模式：随机生成第三关规则的地图，失败后结束

### 游戏中

![第一关](level1.png)

- 鼠标左键点击箭头：发射/移动箭头
- 箭头头部先向前移动，身体段依次跟随
- 前方没有阻挡：箭头逐步飞出棋盘并消除
- 前方存在阻挡：箭头保持原位，并扣除一次失误机会
- `ESC`：返回主界面
- 右上角“重新开始”：重置当前关卡
- 右上角“返回选关”：退回选关界面

### 设置界面

- 点击开关切换窗口模式与全屏模式
- 点击“返回主菜单”返回大厅

### 结算界面

- 通关界面显示最终得分和星级
- 普通关卡可进入下一关
- 最后一关“下一关”按钮为灰色不可用
- 失败界面显示最终得分和 0 星
- 失败后可重新开始或返回选关

## 计分规则

- 每成功消除一个箭头：+10 分
- 时间奖励：用时越短奖励越高
- 失误奖励：剩余失误次数越多奖励越高
- 星级只与剩余失误次数相关

## 其他说明

![无尽模式](endless.png)

- 无尽模式通关后不会重置剩余失误次数
- 无尽模式每通关一次都会随机生成新的可通关地图
